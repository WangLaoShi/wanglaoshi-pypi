# 练习总览

1. 先读对应 Notebook 课  
2. 合上代码，做本页练习  
3. 再打开 Binder / 本地 Jupyter 验证  

```{tip}
练习不要求「标准答案一字不差」。关键是你能说清：**为什么这样划分、为什么这样校验、哪里会泄露**。
```
