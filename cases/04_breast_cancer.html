E04 Breast Cancer（Wisconsin）：量纲、PCA 与召回权衡#

Issue #9 | UCI Breast Cancer Wisconsin

你将学到#

  1. 医学二分类：恶性漏诊（假阴性 FN）代价远高于误报（FP）→ 优先看 Recall

  2. 量纲与缩放：radius/area 等量纲差异大；距离/线性模型前必须 StandardScaler

  3. PCA 理论：用正交主轴压缩方差；mean_* / worst_* / error_* 高度共线（多重共线性）

  4. FeatureImportanceAnalyzer：method='builtin' 读取树模型分裂增益

  5. 分层 CV + 混淆矩阵：FN 即「将恶性判为良性」

指标#

  • Precision–Recall 权衡；阈值非默认 0.5

  • prediction_type='label' 提交练习

本课增补： 可靠性图 / Brier / 固定 10 箱 ECE（校准前后同测试集）。

11. 概率校准：可靠性图、Brier 与 ECE#

对照：sklearn Calibration of Classifiers

在同一测试集上比较校准前后；ECE 使用固定分箱口径（n_bins=10）。

from sklearn.calibration import CalibratedClassifierCV, calibration_curve
from sklearn.metrics import brier_score_loss
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

def expected_calibration_error(y_true, y_prob, n_bins=10):
    y_true = np.asarray(y_true).astype(float)
    y_prob = np.asarray(y_prob).astype(float)
    bins = np.linspace(0.0, 1.0, n_bins + 1)
    ece = 0.0
    for i in range(n_bins):
        m = (y_prob >= bins[i]) & (y_prob < bins[i + 1] if i < n_bins - 1 else y_prob <= bins[i + 1])
        if m.sum() == 0:
            continue
        ece += (m.mean()) * abs(y_true[m].mean() - y_prob[m].mean())
    return float(ece)

pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('clf', LogisticRegression(max_iter=1000, random_state=RANDOM_STATE)),
])
pipe.fit(Xtr, ytr)
prob_raw = pipe.predict_proba(Xte)[:, 1]

# 预拟合校准（用训练折内 CV，避免碰测试集）
calib = CalibratedClassifierCV(pipe, method='isotonic', cv=3)
calib.fit(Xtr, ytr)
prob_cal = calib.predict_proba(Xte)[:, 1]

rows = []
for name, p in [('raw', prob_raw), ('isotonic', prob_cal)]:
    rows.append({
        'model': name,
        'brier': brier_score_loss(yte, p),
        'ece_10': expected_calibration_error(yte, p, n_bins=10),
    })
cal_df = pd.DataFrame(rows)
print(cal_df)

# 可靠性图数据（固定 10 bin）
frac_raw, mean_raw = calibration_curve(yte, prob_raw, n_bins=10, strategy='uniform')
frac_cal, mean_cal = calibration_curve(yte, prob_cal, n_bins=10, strategy='uniform')
out = Path('outputs/04_breast_cancer'); out.mkdir(parents=True, exist_ok=True)
cal_df.to_csv(out / 'calibration_metrics.csv', index=False)
pd.DataFrame({'mean_pred_raw': mean_raw, 'frac_pos_raw': frac_raw}).to_csv(out / 'reliability_raw.csv', index=False)
print('saved calibration_metrics.csv')

附录 B：多重共线性与可解释性#

相关很高时，单系数符号不稳定；树模型的 impurity importance 也会被相关特征分摊。排列重要性（FeatureImportanceAnalyzer method=permutation）更可靠但更慢。

附录 C：从「刷分」到「可部署指标」#

报告模板（作业可抄）：

  1. 验证协议：分层 holdout / StratifiedKFold，种子固定

  2. 主指标：Recall@固定 Precision 或 F1；辅指标 Accuracy

  3. 阈值：默认 0.5 可能不是业务最优——可在验证折扫阈值

  4. 失败案例：抽 5 个 FN 看特征是否异常

FeatureImportanceAnalyzer 用于解释，不能替代协议。

附录 D：特征组语义#

sklearn 乳腺癌数据列名含 mean / error / worst。Worst 往往更可分，但也与 mean 共线。PCA 解释方差曲线帮助决定保留维数。

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
try:
    Xs = StandardScaler().fit_transform(Xtr)
    pca = PCA().fit(Xs)
    cum = np.cumsum(pca.explained_variance_ratio_)
    print('dims for 90% var:', int(np.searchsorted(cum, 0.90)+1))
    print('dims for 95% var:', int(np.searchsorted(cum, 0.95)+1))
except Exception as e:
    print(e)

深度阅读与作业（Breast Cancer）#

必读观点#

  1. 医学二分类必须谈 代价非对称：漏诊（FN）与误报（FP）成本不同。

  2. 多重共线特征组（mean/se/worst）使线性系数不稳；树模型 importance 会被相关特征分摊。

  3. 阈值 0.5 很少是业务最优；在验证折上约束 Precision 下限再最大化 Recall。
