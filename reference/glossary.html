包架构与稳定公开接口（1.15.1+）#

术语

英文 / 符号

含义

稳定公开接口

Facade / public API surface

对外稳定入口子包（设计模式 Facade）；实现细节藏在子模块里

接口模块

facade module

某一稳定公开接口对应的子包，如 compete、analyze

竞赛公开接口

wanglaoshi.compete

提交、基线、泄漏、集成、CV、调参、实验追踪

分析公开接口

wanglaoshi.analyze

EDA / 报告（DataAnalyzer、analyze_data 等）

特征公开接口

wanglaoshi.features

AdvancedFeatureEngineer

分析学公开接口

wanglaoshi.analytics

时序 / 统计 / 校准 / 公平 / 异常 / 排序 / 生存

ML 公开接口

wanglaoshi.ml

预处理与建模；TORCH_AVAILABLE 标识是否装了 torch

运行时公开接口

wanglaoshi.runtime

ready / VERSIONS / JupyterEnv / 字体 / 下载

测试公开接口

wanglaoshi._testing

断言、分数下限、数据台账、实验上下文、回归摘要

业务包

wanglaoshi.business

Skill 固化流水线（接收→清洗→指标→结论→归档）

shim

compatibility shim

根上旧路径转发到公开接口；新代码勿依赖

legacy

soft-deprecated

如 Analyzer_Plain / wqe；导入有警告

静默 legacy

WANGLAOSHI_SILENCE_LEGACY=1

关闭 Plain/wqe 的 DeprecationWarning

推荐导入示例：

from wanglaoshi.runtime import ready
from wanglaoshi.analyze import DataAnalyzer
from wanglaoshi.compete import QuickBaseline, SubmissionGenerator
from wanglaoshi.features import AdvancedFeatureEngineer
from wanglaoshi.analytics import StatsToolkit, TimeSeriesTools
from wanglaoshi.ml import DataPreprocessor, MLModel
from wanglaoshi.business import BusinessPipeline
from wanglaoshi._testing import assert_close

baseline

compete.QuickBaseline

runtime.ready

runtime.VERSIONS

compete.ExperimentTracker

指标登记

evidence replay

SCORE_FLOORS / assert_above_floor

特征与泄漏#

术语

英文 / 符号

含义

特征工程

features.AdvancedFeatureEngineer

衍生、编码、缩放、文本/时间特征

目标编码

target encoding / target_encode

用目标统计编码类别；必须折内

频率编码

frequency encoding / frequency_encode

用出现频次压缩类别；无监督

时间特征

datetime features

从时间戳拆出的周期与滞后候选

滞后特征

lag

用历史值预测未来；禁止用「未来」

数据泄漏

leakage

训练时用不该在预测时可得的信息

时间泄漏

time leakage

用了预测时刻之后的信息

目标泄漏

target leakage

特征直接或间接含目标

折内安全

fold-safe

编码/统计只在当前训练折拟合，再映射到验证折

预处理

ml.DataPreprocessor

术语

英文 / 符号

含义

准确率

accuracy

class_weight

class_weight

术语

英文 / 符号

假设检验与试验#

术语

英文 / 符号

含义

统计工具箱

analytics.StatsToolkit

常见检验与试验辅助入口

试验设计

ExperimentDesign

样本量 / 功效等试验设计辅助

样本量

多重比较
